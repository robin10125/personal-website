Custom Phone Everything App

This app funcitons as a home page and installation system for bespoke smartphone apps and tools I vibe code.

This app allows me to download and update smartphone apps and tools that I make. Often times I find myself wanting a specific tool and feature for my smartphone, so I decided to build an app that allows me to vibe code on the fly these tools and easily download and install them.

An example of a bespoke app I have made with this is a custom stretching timer schedule. I found myself annoyed by constantly resetting my timer after each stretch, so I vibe coded a timer that lets me specify a chain of timers that can repeat an arbitrary number of times. For example, I can set a 1 minute timer, then a 5 second time, and then have this chain repeat 12 times. I used this app to download and install this tool.

Later, when I finish my voice agent app, I'll install it on my phone through this app.

For security regions, the github repo for this project is set to private, but I may release a public version later for others to use.
